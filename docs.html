Overview

FinanceFlow is a comprehensive personal finance management application built for GitHub Pages with Google Sheets as the backend database. It helps you track income, expenses, investments, EMIs, and provides financial calculators.

No server required! FinanceFlow runs entirely on static hosting (like GitHub Pages) and uses Google Sheets + Apps Script as a free backend.

Features

Authentication

Secure login, logout, forgot password with email verification

Dashboard

Overview of balance, income, expenses with charts and quick actions

Accounts

Track bank accounts, credit cards, debit cards, and digital wallets

Transactions

Record income, expenses, transfers with categories and tags

Investments

Track FD, RD, SIP, PPF investments with maturity calculations

EMI Tracking

Schedule EMIs, track payments, get reminders before due dates

Calculators

EMI, FD, RD, SIP, PPF calculators with amortization schedules

Email Alerts

Automated EMI reminders, weekly summaries, auto-expense recording

Calculator Features

  • EMI Calculator - Calculate monthly EMI for home, car, personal loans
  • Reverse EMI Calculator - Find interest rate when you know the EMI (uses binary search algorithm)
  • Amortization Schedule - View monthly or yearly breakdown of principal vs interest
  • FD/RD Calculator - Calculate maturity amount with compound interest
  • SIP Calculator - Project mutual fund returns over time
  • PPF Calculator - Calculate PPF maturity with tax benefits

Setup Instructions

Step 1: Create Google Sheet

  1. Go to Google Sheets
  2. Create a new blank spreadsheet
  3. Name it "FinanceFlow Database"

Step 2: Setup Google Apps Script

  1. In your spreadsheet, go to Extensions > Apps Script
  2. Delete any existing code in the editor
  3. Copy the contents of google-apps-script/Code.gs and paste it
  4. Click Save (Ctrl+S)
  5. Name your project "FinanceFlow Backend"

Step 3: Deploy as Web App

  1. Click Deploy > New deployment
  2. Click the gear icon and select Web app
  3. Set "Execute as" to Me
  4. Set "Who has access" to Anyone
  5. Click Deploy
  6. Authorize the permissions when prompted
  7. Copy the Web App URL

Step 4: Configure Frontend

  1. Open js/config.js
  2. Find DEFAULT_WEB_APP_URL
  3. Replace with your Web App URL

Step 5: Create Users

User Management
Users can only be created through Google Sheets menu. There is no public registration.
  1. Go back to your Google Spreadsheet
  2. Refresh the page to load the custom menu
  3. Click FinanceFlow > Add New User in the menu
  4. Enter the user's name, email, and password
  5. The user account will be created and can now login

Step 6: Setup Email Notifications

  1. In the spreadsheet, click FinanceFlow > Setup Email Triggers
  2. Authorize Gmail permissions when prompted
  3. This creates automated daily and weekly triggers

Step 7: Host on GitHub Pages

  1. Push your code to a GitHub repository
  2. Go to Settings > Pages
  3. Select your branch and root folder
  4. Your site will be live at https://username.github.io/repo

Backend Architecture

How It Works

FinanceFlow uses a serverless architecture with Google Sheets as the database:

Frontend (HTML/JS)  -->  Google Apps Script (Web App)  -->  Google Sheets (Database)

Data Flow

  1. Frontend sends POST request to the Web App URL with action and data
  2. Apps Script receives the request and routes to appropriate function
  3. Function reads/writes data to Google Sheets
  4. Response is sent back as JSON

Authentication Flow

Login Flow

  1. User enters email and password
  2. Frontend sends login action to backend
  3. Backend verifies password hash
  4. Session token is created (30-day expiry)
  5. Token stored in localStorage and Sessions sheet
  6. User redirected to dashboard

Password Reset Flow

  1. User clicks "Forgot Password?"
  2. User enters email address
  3. Backend generates 6-digit code (valid for 15 minutes)
  4. Code sent to user's email
  5. User enters code and new password
  6. Backend verifies code and updates password
  7. All existing sessions are cleared

Security Features

  • Passwords hashed with SHA-256
  • UUID-based session tokens
  • 30-day session expiry
  • Reset codes expire in 15 minutes
  • All sessions cleared on password reset

Troubleshooting

CORS Errors

Opening HTML files directly (file://) will cause CORS errors. Always use a web server.

Solutions:

  • Use GitHub Pages hosting
  • Run local server: python -m http.server 8000
  • Use VS Code Live Server extension

Login Not Working

  • Verify Web App URL in js/config.js
  • Ensure Apps Script is deployed as Web App
  • Check "Anyone" has access to the Web App
  • Redeploy after code changes

Emails Not Sending

  • Run setupNotificationTriggers() from Apps Script menu
  • Authorize Gmail permissions
  • Check email address in notification settings
  • Check Apps Script execution logs for errors

Data Not Syncing

  • Check browser console for errors (F12)
  • Verify Google Sheets API permissions
  • Ensure spreadsheet is not deleted/moved
  • Try clearing localStorage and re-login
